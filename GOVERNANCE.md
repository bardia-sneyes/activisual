# Governance

Activisual is an open-source project with a single maintainer. Anyone may report issues, propose changes, review public work, and contribute through pull requests.

## Maintainer

[Bardia Sneyes](https://github.com/bardia-sneyes) is the project maintainer and repository administrator. The maintainer has final responsibility for:

- project direction and scope;
- accepting, requesting changes to, or declining contributions;
- repository access and GitHub settings;
- releases and npm publishing; and
- security response and disclosure coordination.

Contributing does not grant commit, release, or administrative access. Any future maintainers will be appointed explicitly and documented here.

## Decisions and contributions

Technical decisions are discussed publicly in issues and pull requests whenever practical. The maintainer considers user impact, project scope, security, maintainability, and compatibility across supported harnesses before making a final decision.

Changes enter `main` through reviewed pull requests and must pass the required automated checks. The maintainer may bypass the normal branch rule only for repository recovery or an urgent security response, and should document the reason afterward when disclosure is safe.

Contributions must follow [CONTRIBUTING.md](CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Security vulnerabilities must be reported through the private process in [SECURITY.md](SECURITY.md).
